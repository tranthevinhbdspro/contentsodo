⚙️ 2. Tôi có bắt buộc phải mua API Key hay nạp tiền AI để dùng không?

☁️ 4. Khi tôi đổi máy tính mới hoặc cài lại điện thoại thì dữ liệu có bị mất không?
Để an toàn tuyệt đối, bạn hãy dùng tính năng ☁️ Sao Lưu Cloud (Drive). Trước khi đổi máy, bấm "⬇️ Xuất File Sao Lưu (.JSON)" và lưu vào Google Drive cá nhân. Khi sang máy mới, bạn chỉ cần chọn "📂 Phục Hồi Dữ Liệu Từ File JSON" là toàn bộ khách hàng, rổ hàng và lịch đăng sẽ khôi phục lại 100%.
